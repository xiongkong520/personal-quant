# 社区 / 机构做法调研：市场状态、主线、仓位与因子

> 项目：个人量化工作台（A股，日频，AKShare 数据源）
> 调研时间：2026-11-22 ｜ 调研方式：公开检索 + 一手研报/官方文档核对 + 本机 AKShare 1.20.65 接口实测
> 定位：**研究报告，不构成投资建议**。文中所有收益/IC 数字均为**历史统计，不代表未来**。
> 标注约定：`【机构研究】` 指券商/学术研究口径；`【社区共识】` 指量化社区与交易社区反复出现的做法（非权威）；`【社区KOL】` 指自媒体/投顾老师的个人经验；`【开源项目自述】` 指项目 README 作者自述；`【个人观点】` 指本文作者判断。

## 0. 核心结论（先看这 5 条）

1. **市场状态判断的通行结构是「三层」：趋势/风险开关层 + 市场宽度层 + 情绪周期层**，单看指数涨跌会被权重股骗。机构与社区在"看什么"上高度一致，分歧主要在"阈值取多少"，而阈值本身随市场结构漂移（机构也称之为"后验阈值"）[R2][R3]。
2. **情绪周期最硬的指标是涨停/跌停家数、连板高度、晋级率、炸板率、成交额分位**；这些在 AKShare 里都有现成接口（本机实测 1.20.65 可用），改造成本低、信息增益大 [R4][R20]。
3. **板块/主线的主流做法是「相对动量排名 + 多维打分 + 拥挤度修正」**；社区"主线"定义（政策催化+资金认可+涨停集群+趋势+热度）本质是这一套的定性版，可规则化 [R8][R9][R10]。
4. **仓位管理最可落地的是「状态分档 × 波动率目标」**：波动率目标有学术与实证支持 [R13]；凯利公式与风险平价 [R12] 更适合做参考值，不适合直接进散户下单逻辑（参数估计误差大）。
5. **因子侧最重要的不是堆数量，而是评估口径与预期管理**：两个独立个人项目分别自述"四个简单因子全样本 RankIC≈0"与"真实 A 股 |IC|<0.07"，说明简单价量因子 alpha 很弱（历史统计、不代表未来）[R21][R24]。本项目已有 IC/RankIC/ICIR/分层框架，下一步应补"中性化、10 分组、IC 衰减、分状态 IC"，而不是扩因子名单。

## 1. 市场状态 / 大盘判断

### 1.1 主流框架：三层指标

| 层 | 作用 | 代表指标 | 出处 |
|---|---|---|---|
| 趋势 | 判断"能不能做"的方向 | 宽基指数均线（20/60/200/250 日）、指数动量、已实现波动率 | [R1] |
| 风险开关 | 判断 `risk-on / risk-off` 全局风险偏好 | 股债相对强弱、信用利差、汇率与商品、跨资产联动 | [R14] |
| 市场宽度 | 判断行情"健不健康"（是否少数权重股拉指数） | 上涨/下跌家数、% 高于 50/200 日均线、腾落线 ADL、新高新低、涨跌幅中位数 | [R1][R5][R6] |
| 情绪周期 | 判断"冰点 / 修复 / 狂热 / 退潮"与过热风险 | 涨停家数、跌停家数、最高连板、1进2 晋级率、昨日涨停今日溢价、炸板率、成交额分位 | [R2][R3][R4] |

【机构研究】券商情绪专题把情绪拆成**五个维度**：交易热度、结构热度、赚钱效应、杠杆资金、风险偏好；做法是各子指标取分位数、等权平均后标准化成 0–100 指数，并以 **20 / 80** 作为"极度恐慌 / 极度贪婪"阈值；周期分四阶段（冰点期、修复期、狂热期、退潮期）。其结论是情绪指标"**先动量、后反转**"，且**底背离信号优于顶背离**（2016–2026 共 2581 个交易日，检出 13 次顶背离、16 次底背离）——这是历史统计、不代表未来 [R2]。

【机构研究】广发证券《风险偏好的识别体系》给出可操作的三环节与**后验阈值**（注意作者自己强调是"后验"，即按历史经验反推，不是普适常数）[R3]：

- **指数氛围**：指数维持区间震荡或上涨，且成交额维持在 **1.2–1.5 万亿元以上**；
- **短线情绪**：涨停数量 **60–90 家以上**、连板高度维持 **5–7 连板或以上**、跌停数量维持在 **10 家以内**（不扩散）；
- **赚钱效应（赔率）**：昨日涨停股今日溢价（连板指数涨幅）通常需维持 **3–5% 或以上**；另看各连板梯队**晋级率**（胜率）与龙头示范效应。

【社区共识】散户/短线社区常用的"情绪指数"与阈值，以韭研公社复盘模板为例：取 **8 个指标**（涨停家数、上涨占比、最高连板、1进2 晋级率、昨日涨停股今日表现、跌停家数、大幅回撤、炸板率）折算 0–100 分，按**赚钱效应 / 接力意愿 / 市场广度 / 亏钱效应四层各 25%** 加权；**70 以上偏热、30 以下偏冷**；并画出阈值线：涨停 50 家、跌停 10 家与 30 家、炸板率 30% 与 50% [R4]。

【社区共识】市场宽度指标清单（社区工具文档口径）：涨跌家数比（ADR，>1 多头占优）、上涨占比（>50% 赚钱效应好）、涨跌幅中位数（比均值更贴近多数人体验）、涨停/跌停家数（排除 ST/新股）、**炸板率**（曾涨停未封住 / 曾涨停）、强势股占比（涨幅>3%）与弱势股占比（跌幅>3%）、以及**宽度背离检测**（指数新高但上涨家数减少）[R6]。

【机构研究 / 教科书口径】% 高于 N 日均线：计算简单（高于均线只数 / 总只数），以 **50% 为中枢**，**>70% 视为超买、<30% 视为超卖**，但不同指数阈值可不同；在多条超买读数连续出现时，是"强势"信号而非卖点 [R1]。腾落线（ADL）= 每日（上涨家数 − 下跌家数）的累计；**指数涨而 ADL 不涨/下跌 = 宽度背离**，是回调前兆；底部 ADL 先拐头则是企稳信号 [R5]。

### 1.2 关键指标与阈值速查

| 指标 | 常见口径 / 阈值 | 性质 |
|---|---|---|
| % 高于 50/200 日均线 | 50% 中枢；>70% 超买、<30% 超卖 | 机构/教科书 [R1] |
| 上涨占比 | >50% 赚钱效应好；<15% 且跌停多于涨停 → 冰点 | 社区 [R6] + 本项目已有 |
| 涨停家数 | 50 家（社区阈值线）；60–90 家以上（活跃资金积极阶段） | [R3][R4] |
| 跌停家数 | 10 家以内（不扩散）；30 家为恶化阈值线 | [R3][R4] |
| 最高连板 | 5–7 板以上 = 情绪活跃；社区常以 3 板定龙头、8–10 板为极强 | [R3][R11] |
| 炸板率 | 30% / 50% 两条阈值线；抬升 = 接力意愿下降 | [R4][R6] |
| 成交额 | 1.2–1.5 万亿以上支撑持续性行情；社区"2 万亿以上"为强情绪参考 | [R3][R11] |
| 情绪指数 | 0–100，<20 极度恐慌、>80 极度贪婪；社区 70/30 分界 | [R2][R4] |
| 风险开关 | risk-on / risk-off 不是单一指标：用多资产变量（股/债/信用/汇率/商品）联合刻画；学术研究把 risk-on/off 冲击作为一类可识别的宏观冲击 | 学术研究 [R14] |

> ⚠️ 阈值不是常数。机构报告明确称其阈值为"后验"[R3]；本项目 `market.py` 里 20/40/60/80 的固定阈值同样面临市场结构漂移风险，建议改成分位数或配置化（见 §1.4）。

### 1.4 对本项目的可执行建议

**现状**：`src/quant/data/market.py` 已实现 0–100 情绪分（涨跌家数宽度 50% + 涨停跌停比 30% + 活跃度 20%）、5 档情绪（20/40/60/80）、冰点强判定（宽度<15% 且跌停多于涨停）。另据工作区**未提交**的 `src/quant/data/regime.py`（task-7，并行开发中）已有大盘状态机：状态分 = 0.45×趋势分 + 0.40×情绪分 + 0.15×量能分，按 70/55/42 切 5 档（进攻/偏多/震荡/偏空/冰点布局）+ 冰点守卫，并给出状态→仓位区间建议。两者的共同缺口是：阈值与权重均为硬编码、情绪分仍只由宽度/涨停比/活跃度三项构成、无连板高度/炸板率/晋级率/成交额分位、无状态持续天数与滞后确认。

1. **阈值配置化 + 分位模式**（P0）：把 `market.SENTIMENT_STATES`（20/40/60/80）与 `regime` 的状态切分（70/55/42）及权重（0.45/0.40/0.15）挪到 `config/default.yaml`，新增 `mode: fixed | quantile`；quantile 模式用过去 250 个交易日的分数分布取分位，避免牛熊切换后状态失真。
2. **补 4 个情绪硬指标**（P0）：`连板高度 = max(stock_zt_pool_em.连板数)`；`炸板率 = len(zbgc)/(len(zt_pool)+len(zbgc))`（`stock_zt_pool_zbgc_em`）；`1进2 晋级率 = 昨日首板(昨日连板数==1)且今日涨停数 / 昨日首板数`（`stock_zt_pool_previous_em` 同时给出"昨日涨停股今日涨跌幅"，可直接算社区口径的"接力赚钱效应/赔率"）；`成交额分位`（两市成交额相对过去 250 日的分位）。涨停池还带 `涨停统计`（N天M板）、`封板资金`、`首次封板时间`，可用于龙头强度打分。接口本机已验证存在，见 §6。
3. **状态机加滞后与持续期**（P0）：状态需连续 2 日确认才切换（hysteresis），输出 `state_since` / `days_in_state`（两处实现目前都没有）；避免阈值附近抖动导致看板"来回跳"。
4. **子分项外露**（P1）：`sentiment` 增加 `sub_scores`（breadth / limit / height / amount / leverage），前端可解释"为什么今天是冰点"，也便于回测做归因。
5. **宽度层补 % 高于 20/60 日均线**（P1）：需要全市场日线池（当前只维护 3 只 symbol）。最低成本方案：每日一次 `stock_zh_a_spot_em()` 快照存 DuckDB，滚动 60 日后即可算均线上方比例；短期可先用"涨幅>3% 占比"替代并在报告标注口径。
6. **风险开关不做复杂模型**（P2）：A股散户可用的简化版 = 指数 20/60 日动量 + 成交额分位 + 情绪分，三者同向时给"risk-on/off"标签即可；学术派的多元复合指标 [R14] 需要更多资产数据与更长样本，对个人工作台性价比低、可解释性差。

## 2. 板块轮动与主线识别

### 2.1 主流做法

【机构研究】行业轮动的多维打分框架：从**基本面、分析师预期、资金流、量价、估值**五个维度刻画行业相对收益机会，再用**拥挤度约束**修正极端拥挤行业的排序；组合层面设**单行业暴露上限**（示例 ≤35%），每月末按综合评分选 10 只指数等权持有。该报告自述 2018–2026.10 回测年化 17.75%（等权基准 2.41%）、波动率 27.68%、Sharpe 0.72 —— 历史统计、不代表未来，且报告自身提示"历史规律可能失效、因子存在阶段性失效、样本选择偏差" [R8]。
【机构研究】拥挤度修正的具体做法（西南证券）：从**情绪扩散、资金拥挤、量能交换**三维构建行业相对交易状态指标（RDSI 相对扩散情绪指数、RITC 相对交易集中度、IRT 相对换手率），发现 **RDSI 存在拥挤度门槛效应**：RITC 中低位时 RDSI 与未来收益稳定正相关，RITC 突破临界值后 RDSI 失效、IRT 转为显著负向溢价；因此采用"非拥挤域用情绪动量、高拥挤域用换手率排雷"的动态切换 [R9]。

【社区共识】相对轮动图（RRG）：用 RS-Ratio（相对强弱）与 RS-Momentum（相对动量）把板块分到 leading / weakening / lagging / improving 四象限，用于判断"谁在领涨、谁在转弱"；机构与交易社区都用它做板块轮动可视化 [R7]。

【社区KOL】"主线"的定性定义（九方智投投顾文章，属个人经验，非机构结论）：主线 = 有强故事（政策/新闻催化）+ 资金持续认可（板块成交额占据市场前列、连续净流入）+ 板块内涨停集群（每天多只涨停，形成梯队）+ 技术趋势（板块指数/龙头多头排列、创阶段新高）+ 市场讨论热度；并强调"容量"（大板块行情走得更远）与"持续性"（非一日游）[R10]。另一篇给出更具体的情绪与资金门槛：涨停家数 80–100 家以上、成交额最好 2 万亿以上、连板高度 5 板甚至 8–10 板、板块**连续 3 天净流入且每日超百亿**、用"三板定龙头"识别龙头、首板阶段量化可平铺 [R11]。
> 这些数字是社区经验值，与机构"后验阈值"性质相同：**样本外稳健性未经验证**，仅可作为指标清单参考。

### 2.2 关键指标与判定规则

| 维度 | 指标 | 常见口径 |
|---|---|---|
| 相对动量 | 行业指数 20 日 / 60 日收益 − 宽基同期收益 | 社区工具默认 20/60 日窗口；RRG 用相对强弱 + 相对动量两条线 [R7]，ETF 轮动研报多用月频调仓 [R8] |
| 资金流 | 板块主力净流入、连续净流入天数、成交额占全市场比重及分位 | 研报"五维"之一 [R8]；社区"连续 3 日净流入超百亿"[R11] |
| 涨停梯队 | 板块内涨停家数、最高连板、首板/2板/龙头数量 | 主线最直接证据 [R10][R11] |
| 强势持续 | 动量排名连续在前 N 名的天数、板块指数创 20/60 日新高 | 轮动持续性判断；RRG 看四象限迁移 [R7] |
| 拥挤度 | 成交额占比分位、换手率分位、RDSI/RITC/IRT | 机构拥挤度框架 [R9] |
| 宽度 | 板块内上涨家数占比、% 高于 20 日均线 | 扩散度判断 [R9] |

【个人观点】可把"主线"落成可解释规则（比聚类/LLM 更稳）：`mainline_score = 0.35*动量排名 + 0.25*成交额占比分位 + 0.25*涨停/连板梯队 + 0.15*板块宽度`；连续 5 日在前 3 名且至少 3 家涨停记为"主线候选"；成交额占比分位 >90% 且换手率分位 >90% 时打"拥挤"标记并只保留龙头。权重需回测校准，不是真理。

### 2.3 对本项目的可执行建议

**现状**：未提交的 `src/quant/data/regime.py`（task-7）已实现板块层：同花顺行业/概念资金流为首选（`stock_fund_flow_industry_ths` / `stock_fund_flow_concept_ths`，取当日 + 5 日排行），东财 `stock_board_industry_name_em` / `stock_fund_flow_sector_rank_em` 兜底；主线综合分 = 当日涨幅百分位×0.34 + 5 日涨幅百分位×0.33 + 净流入百分位×0.33，输出 Top5、连续上涨天数与概念黑名单过滤。**缺口**：没有相对宽基的超额动量、没有涨停梯队/连板高度、没有成交额占比与拥挤度标记，且"连续强势"只按连续收阳计（不等于连续跑赢）。

1. **在已有板块层上补三件**（P1）：① 相对动量 `mom_20/mom_60(板块) − mom_20/mom_60(沪深300)`（用 `stock_board_industry_hist_em` 缓存板块历史，接口已实测存在）；② 涨停梯队：用 `stock_zt_pool_em` 的 `所属行业` 直接聚合 `涨停家数 / 最高连板 / 封板资金合计`（`涨停统计` 给出 N 天 M 板，可识别"板块内高度"）；③ 拥挤度：板块成交额占全市场比重及其 250 日分位、换手率分位。建议先作为独立标记输出、不改已定权重，便于 A/B 对比。
2. **主线评分扩维**（P1）：把上面三件并入 `regime.json` 的 `leaders[]`（现有字段已有 score/tag/days），并新增 `mainline_candidates`（连续 5 日综合分前 3 + 至少 3 家涨停）与理由字段；前端加"板块热度"卡片。
3. **主线规则先展示、不交易**（P1）：规则版输出只进看板与报告，不做自动切换持仓；积累 3–6 个月样本后再评估。

## 3. 仓位管理模型

### 3.1 主流做法与依据

| 模型 | 核心公式 / 思路 | 适用性与出处 |
|---|---|---|
| 固定比例 + 再平衡 | 每票固定总资金比例，定期或阈值再平衡 | 最简单、最稳，社区新手默认（社区共识，无单一权威出处） |
| 波动率目标（vol targeting） | `exposure = target_vol / realized_vol`，波动高时降暴露 | 学术支持：按因子波动率调整风险暴露可提升风险调整收益，因为波动率变化没有被预期收益同比例抵消（Moreira & Muir, NBER w22208）[R13] |
| 风险平价 / ERC | 让每个资产对组合风险的贡献相等；散户版 = 权重 ∝ 1/σ 后归一化 | AQR 的杠杆厌恶理论解释：低 beta 资产风险调整收益更高，RP 组合在杠杆约束下更优 [R12] |
| 凯利公式 | `f* = p − q/b`（p 胜率、q=1−p、b 盈亏比）；实务用半凯利/四分之一凯利 | 经典综述见 Thorp《Optimal Gambling Systems for Favorable Games》[R26]；全凯利对胜率估计误差极敏感，实务普遍降杠杆（社区共识） |
| 状态分档 | 按市场状态给基准暴露（如 冰点 0.2 / 中性 0.5 / 过热 0.3） | 社区共识做法，直观、可解释，但分档与阈值是启发式，必须回测验证 |

【社区共识】散户可落地的简化组合：**总仓位不超过某上限 + 单票上限 + 波动率倒数分配 + 状态分档**；"看不懂就轻仓/空仓"是社区反复出现的风控原则（各类量化入门文章与交易社区一致，属共识而非研究结论）。
【个人观点】对个人工作台，最值得做的不是追求"最优仓位公式"，而是**把仓位建议显性化、可回测、可解释**：同一套信号在不同仓位规则下的净值差异，本身就是最有价值的研究产出（社区文章也强调"同样的买卖信号，不同仓位规则，收益与回撤天差地别"）。

### 3.2 关键参数与阈值

- **目标波动率**：个人组合常用年化 15%–20%（经验值，非研究结论）；本项目 `paper` 配置已有单票上限 `max_position_pct: 0.2`，可加 `target_vol`。
- **波动率缩放上限**：`min(1.5, target_vol / realized_vol)`，无杠杆场景下上限取 1.0（只用降暴露）。
- **已实现波动率窗口**：20 日（短）与 60 日（长）各取一半或取较大者，避免单窗口噪声。
- **回撤熔断**：净值回撤 −10% 降一档、−20% 暂停新开仓（经验值，需回测，历史统计不代表未来）。
- **凯利上限**：`f_used = min(0.5 * f_kelly, max_position_pct * 2)`；且 p 用 **Wilson 95% 下界**而不是点估计（项目回测已输出 Wilson CI，正好可用）。

### 3.3 对本项目的可执行建议

**现状**：`paper/engine.py` 有单票 20% 上限、手续费/印花税/滑点/整手/T+1；未提交的 `regime.py`（task-7）已给出状态→仓位区间建议（进攻 6-8 成 / 偏多 4-6 成 / 震荡 2-4 成 / 偏空与冰点 0-2 成）与加减仓触发条件，但**没有波动率目标、没有回撤熔断、没有历史校准**，且 `config/default.yaml` 里没有任何仓位参数。

1. **新增仓位配置**（P1）：`position: {state_exposure: {offense: [0.6, 0.8], lean_bull: [0.4, 0.6], range: [0.2, 0.4], lean_bear: [0, 0.2], ice_watch: [0, 0.2]}, target_vol: 0.18, vol_window: 20, dd_stop: 0.2}`（与 `regime.STATE_POSITION` 对齐，避免两套口径）。
2. **在 `regime.position_advice` 上叠加波动率缩放**（P1）：`建议仓位 = 区间中值 × min(1.0, target_vol / realized_vol_20)`；再按 `1/σ_i` 分配个股权重，受 `max_position_pct` 与整手约束。**只输出建议，不自动下单**（研究工具定位）。
3. **回测对比三套仓位规则**（P1）：固定满仓 / 状态分档 / 状态分档×波动率目标，同口径同成本并列净值、回撤、Sharpe（沿用 §12.2 口径与基准对比要求）。这是判断"分档表该取多少"的唯一可靠办法。
4. **凯利只做展示**（P2）：在报告中给出 `half_kelly` 参考值与"胜率 Wilson 下界"，明确标注“仅供参考，不进入下单逻辑”。理由：本项目信号胜率的样本量与估计误差都撑不起全凯利（参考 [R21] 中"简单因子 RankIC≈0"的提醒）。
5. **拥挤度/相关性约束**（P2）：若后续加入板块层，限制单行业暴露（参考机构 35% 上限 [R8]），并做持仓相关性检查，避免"5 只票 1 个板块"。

## 4. 因子体系

### 4.1 因子分类

- **qlib Alpha158**：官方数据集中 158 个表达式因子，按 K 线形态（KMID/KLEN/KUP/KLOW/KSFT 等）、静态价格、趋势（ROC/MA）、波动、量价相关等分组构建 [R19]；qlib 文档把因子/模型的收益预测统一到"每日给全市场打分"的范式，并用 IC 与组合收益两条线评估 [R17][R18]。
- **社区常用四分法**：价量因子（动量/反转/波动/换手/流动性）、财务因子（估值 PE/PB、质量 ROE/SUE、成长）、分析师因子（预期上调、覆盖度）、另类因子（舆情、事件、资金流）。本项目已有 18 个价量因子，属第一类（与 [R24] 的因子清单同构）。
- **风格/风险模型口径**：Barra 式风格（size、beta、momentum、residual vol、liquidity、value、growth、leverage 等），用于中性化与归因；社区项目常用"行业 + 市值"两层中性化，因为最容易获取 [R24]。

### 4.2 评估标准（IC / RankIC / ICIR / 分层）

| 指标 | 定义 | 经验门槛 |
|---|---|---|
| IC | 每日截面上 `corr(因子值, 未来收益)` 的 Pearson 相关，序列取均值 | \|IC\| > 0.02–0.03 才有参考价值；A股真实因子常 <0.07 [R24] |
| RankIC | 同上但用 Spearman 秩相关，抗极值 | 与 IC 同量级；两者差距大说明极值影响大 |
| ICIR | `mean(IC) / std(IC)`（时序稳定性） | \|ICIR\| > 0.3–0.5 较好；本项目 `evaluation.py` 用 0.5 |
| t 值 | `ICIR × sqrt(n_days)` | \|t\| > 2 才算统计显著 |
| 分层 | 按因子值分 5/10 组，看各组下期收益是否单调 | 单调性 + Top-Bottom spread 同向；社区项目常见"中性化后分层净值"图 [R24] |
| 多空组合 | Top 组 − Bottom 组，年化收益与 t 值 | A股融券难，**更看多头组相对基准超额**（社区共识；机构研报也常并列多头超额） |

【机构研究】因子检验流程通常是：IC 检验 → 分组单调性（十分组）→ 多空组合收益 → 市值/行业中性化后再做一遍 → 纯因子回归检验；qlib 官方评估同样分"IC 相关"与"组合收益"两条线 [R18]，社区项目则普遍做中性化后的分组对比 [R24]。【社区共识】A股融券难、做空成本高，因此**多头组相对基准的超额**比多空 spread 更有实际意义。海通的两篇报告进一步说明：
- **因子有效性随市场环境切换**：下跌市中短期大涨后，小市值、反转、高 beta 表现突出而基本面因子转弱；结构化行情扩大时基本面因子显著减弱；成交放大时价量/情绪类因子更强。且**因子间相对强弱的平均持续时间约 1 个月**，随后较快修复 [R15]。
- **因子有效性随组合规模衰减**：用历史成交额约束股票池后，换手率、特质波动率与高频因子的 IC 随规模上升明显下滑，周度换仓比月度更严重；不能简单用"全 A 股测试结果"评估实盘因子 [R16]。

### 4.3 A股常见有效因子与衰减（历史统计、不代表未来）

| 因子 | 社区/研报共识 | 衰减与风险 |
|---|---|---|
| 短期反转（1–5 日） | 【社区共识】A股散户结构下短期反转效应常被讨论；本项目已含 `rev_1` | 交易成本敏感（换手高），扣费后可能消失 |
| 低波动 / 低换手 | 防御属性，下跌市中相对占优 [R15] | 牛市弹性差；拥挤后失效 |
| 小市值 / 规模 | 长期存在超额，但**时变性极强**：机构研报指出小市值因子与"上涨弹性"相关，下跌市短期大涨后表现突出、结构化行情减弱后期表现较差 [R15]；社区复盘认为 2013–2016 壳资源行情强、2017–2018 走弱、2021 起小市值回归、2024 年显著回撤（社区观点，非定量依据）[R25] | 容量小、流动性差、政策与退市规则风险；**不要当稳定 alpha** |
| 质量（ROE/SUE） | 基本面因子在市场剧烈波动时相对占优 [R15] | 数据披露滞后，需做 point-in-time；A股财报季效应 |
| 动量（中期） | 社区常做 20/60 日动量；但 A股短期反转与中期动量孰强**不同样本期结论不一**【社区观点】 | 反转/动量切换频繁，需分状态统计 |
| 流动性 / 换手率 | 低换手、低流动性溢价在 A股长期存在；拥挤度是失效前兆 [R9][R16] | 规模上升即衰减 [R16] |

【开源项目自述 · 预期管理】两个独立个人项目都给出"泼冷水"结论：
- **swell-quant**：100 只沪深300 成分、2016–2026、90 个样本外期，动量/低波/质量/成长四个简单因子**全样本 RankIC ≈ 0**，作者据此认为"没有可信的选股 alpha"，并把项目目标定为"诚实告诉你信号有没有用" [R21]。
- **quant-portfolio**：沪深300 五因子 + 行业市值中性化，作者结论"真实 A 股因子 IC 较弱（|IC|<0.07），中性化后 IC 下降属正常现象"，最优组合回测年化 8.2%、Sharpe 0.26、最大回撤 −28.8%（2020-01–2024-12，历史统计、不代表未来）[R24]。
> 这两个结论是**单项目自述**，不能当作"因子无用"的定论；但足以说明：本项目应把重心放在**评估口径与预期管理**上，而不是追求因子数量。

### 4.4 对本项目的可执行建议

**现状**：`factors/library.py` 有 18 个价量因子（动量/反转/波动/乖离/RSI/量比/振幅/位置/跳空/Amihud/换手/涨停次数），`evaluation.py` 已实现每日截面 MAD 去极值 + z-score、IC/RankIC/ICIR/t/胜率、5 分组与单调性、Top-Bottom spread —— 框架已达标，缺"中性化、10 分组、衰减、分状态、成本"。

1. **评估增强（P0，成本最低收益最高）**：`evaluation.py` 增加 (a) 10 分组并输出多空组合年化与 t 值；(b) IC 衰减曲线（`lag=0..10`，看信号能活几天）；(c) 因子相关性矩阵（避免 18 个因子其实是 5 个）；(d) 每日截面样本数分布（`n_days` 太少要标注）。
2. **标签口径（P0）**：`fwd_ret` 改为可配 horizon，至少同时输出 1/5/10/20 日；并**剔除涨跌停无法成交的样本**（项目已有 `limit_up/limit_down` 列，直接可用），否则回测会系统性高估。
3. **分状态 IC（P1）**：把 `regime.py` 的 5 档状态（或 `market.py` 的情绪 5 档）接到因子评估上，输出每个状态下各因子 IC/多空收益 —— 直接复刻海通研报的"不同市场环境下因子表现"思路 [R15]，这是本项目"市场状态 × 因子体系"两块的天然结合点，也是最可能做出差异化的地方。
4. **中性化（P2）**：加行业 + 市值中性化（OLS 残差），参考社区项目做法 [R24]；需要行业分类与总市值数据，AKShare 可获取（`stock_board_industry_name_em` + 市值字段）。
5. **IC 加权与半衰期（P2）**：多因子合成时用滚动 IC 或 IC 半衰期加权（社区项目对比过等权/滚动 IC/半衰期 IC，结论是主要改善稳定性而非收益 [R24]）。
6. **财务因子暂缓**（P2）：质量因子（ROE/SUE）需要 point-in-time 财务数据，接入成本高且易踩未来函数；当前 3 只票的股票池也不支持截面因子，建议股票池扩到 ≥100 只后再做。

## 7. 优先级建议清单（P0 / P1 / P2）

**P0（先做，成本低、直接影响看板可信度）**
1. **情绪/状态阈值配置化 + 分位模式 + 状态滞后**：`market.py` 的 20/40/60/80 与 `regime.py` 的 70/55/42、0.45/0.40/0.15 权重都是硬编码，市场结构变化后会失真；改成可配置 + 250 日分位 + 连续 2 日确认，看板立刻更稳。
2. **补 4 个情绪硬指标（连板高度、炸板率、1进2 晋级率、成交额分位）**：机构与社区的"情绪"定义里都有它们，而本项目目前只有涨跌家数与涨停比；改在 `market.compute_sentiment` 一处，`regime.py` 与看板同时受益。
3. **补契约 §13 市场快照 / §15 状态引擎章节**：`market.py` 声称遵循 §13、`regime.py` 声称遵循 §15，但 `docs/CONTRACT.md` 只写到 §12，属于口径漂移隐患，后续多人开发必然踩坑。
4. **因子评估补 10 分组/多空年化与 t/IC 衰减曲线/因子相关性矩阵**：框架已有 80%，补齐后"因子有没有用"才说得清；同时把涨跌停不可成交样本从 `fwd_ret` 里剔除，避免高估。

**P1（有价值，需几天到一两周）**
5. **在已有板块层上补三件（20/60 日相对动量、涨停梯队、拥挤度标记）**：`regime.py` 板块层只有当日/5 日涨幅与净流入，缺少"持续跑赢"与"过热"证据；补齐后再谈主线识别，先展示、不交易。
6. **在 `position_advice` 的仓位区间上叠加波动率目标，并做三套仓位规则回测对比**：波动率目标有学术支持 [R13]，且能让"同样的信号、不同仓位"的差异可视化，是当前最有研究价值的增量。
7. **分状态因子 IC**：把市场状态与因子评估打通，复刻海通研报"不同市场环境下因子表现"的思路 [R15]，也是本项目"状态仪表盘 × 因子体系"的差异化卖点。

**P2（后置，成本高或依赖数据/样本积累）**
8. **行业 + 市值中性化与财务因子（ROE/SUE）**：需要行业分类、市值、point-in-time 财务数据，且当前股票池太小、截面因子无意义；先把股票池扩到 ≥100 只。
9. **凯利 / 风险平价的"参考值"展示**：只展示 half-Kelly（胜率用 Wilson 下界）与 ERC 权重，不进下单逻辑；现在样本量撑不起全凯利。
10. **研究结论库（借鉴 QuantMind 的 typed knowledge + as_of + 引用）**：把每次回测/因子结论沉淀成带时间戳、带来源的卡片，避免重复踩坑；长期收益高但可延后。

## 9. 方法与局限

- **方法**：以「社区做法 vs 机构研究 vs 开源实现」三源交叉核对；指标定义以官方文档/研报为准，阈值只记录其**原始来源口径**，不做二次推断；本机 AKShare 接口以实际导入与源码字段核对（akshare 1.20.65），避免"文档写了但接口已改名"的坑。
- **局限 1：阈值不可移植**。机构称"后验阈值"、社区数字来自不同样本期；本文列出的所有阈值都应视为**待回测的候选参数**，而不是可直接使用的规则。
- **局限 2：检索到的是摘要与二手转述**。券商研报正文受版权限制，本文引用的是公开摘要页；结论以摘要可核实部分为限。R25 为社区文章（非权威），仅用于说明"小市值因子时变性"的社区叙事，不作为定量依据。
- **局限 3：社区观点与机构结论不等价**。本文用标注区分二者；凡社区KOL数字（涨停 80–100 家、成交额 2 万亿、连续 3 日净流入百亿等）均未在机构研究中找到同口径验证。
- **局限 4：收益数字全部为历史统计**。文中出现的年化收益、Sharpe、IC、回撤等均为对应来源的历史回测或统计结果，**不代表未来**；本项目为研究学习工具，**不构成任何投资建议**。
- **局限 5：工作区状态在写作期间变化**。本报告完成时工作区存在未提交的 `src/quant/data/regime.py`、`scripts/regime_report.py`、`tests/test_regime.py`（task-7 并行开发中）；§1–§3 的"现状"与建议已按其实现校准，但该模块仍在变动，实施前请与其负责人确认，避免双实现。
